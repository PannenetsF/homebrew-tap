# homebrew-tap

Homebrew formulae by [@PannenetsF](https://github.com/PannenetsF).

## Usage

```sh
brew tap PannenetsF/tap
brew install aerospace-hud
```

Or in one line:

```sh
brew install PannenetsF/tap/aerospace-hud
```

## Formulae

- **[aerospace-hud](https://github.com/PannenetsF/aerospace-hud)** — a
  lightweight per-monitor workspace HUD for the
  [AeroSpace](https://github.com/nikitabobko/AeroSpace) window manager.
- **[keybr-tui](https://github.com/PannenetsF/keybr.com/tree/main/packages/tui)**
  — the [keybr.com](https://www.keybr.com) touch-typing practice engine in the
  terminal.
